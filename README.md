# Data Scientist / AI — Zadania domowe

Repozytorium zawiera moje rozwiązania zadań domowych realizowanych w ramach zajęć **Data Scientist / AI**.

Celem repozytorium jest systematyczne gromadzenie wykonanych ćwiczeń, projektów oraz materiałów związanych z analizą danych, uczeniem maszynowym i sztuczną inteligencją.

## 📚 Zakres tematyczny

W repozytorium będą pojawiać się zadania związane m.in. z:

* Data Science
* analizą i przetwarzaniem danych
* Pythonem
* statystyką i analizą danych
* wizualizacją danych
* uczeniem maszynowym (Machine Learning)
* sztucznymi sieciami neuronowymi
* Deep Learning
* sztuczną inteligencją (AI)
* oceną i porównywaniem modeli
* efektywnością modeli AI
* przygotowaniem danych do modeli
* praktycznymi zastosowaniami AI
